# Игра «Цвета»

Одностраничная детская игра для изучения названий цветов на английском языке.
Каждый из девяти цветов появляется один раз в случайном порядке. Фигура плавно
закрашивается снизу вверх за 15 секунд, таймер тикает каждую секунду, после чего
звучит сигнал и показывается правильный ответ.

## Запуск

Откройте `index.html` в браузере. Интернет и установка программ не нужны.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория все файлы и папку `assets`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.

## Как добавить цвет

Откройте `game.js` и добавьте строку в массив `COLORS`:

```js
{ english: "BROWN", russian: "коричневый", value: "#8b5a2b" },
```

Счётчик раундов и точки прогресса подстроятся автоматически.

## Как добавить CSS-фигуру

1. Добавьте объект в массив `ARTWORKS` в `game.js`:

```js
{ type: "css", name: "Трапеция", shape: "trapezoid" },
```

2. Добавьте контур в `styles.css`:

```css
.css-artwork[data-shape="trapezoid"] {
  --shape-path: polygon(20% 5%, 80% 5%, 100% 95%, 0 95%);
}
```

## Как добавить PNG-картинку

Подготовьте PNG с прозрачным фоном и **замкнутыми** чёрными линиями. Поместите
его в папку `assets`, затем добавьте объект в массив `ARTWORKS`:

```js
{ type: "image", name: "Яблоко", src: "assets/apple.png" },
```

Игра автоматически определит прозрачную область внутри замкнутого контура и
будет заполнять её цветом снизу вверх. Контур не должен иметь разрывов, иначе
часть заливки может выйти за его пределы.

## Основные настройки

- `ROUND_DURATION_MS` — продолжительность раунда, сейчас 15 секунд.
- `ANSWER_DURATION_MS` — сколько показывать правильный ответ перед новым раундом.
- `COLORS` — список цветов.
- `ARTWORKS` — список CSS-фигур и PNG-картинок.
